# Instructions for AI agents / CLI tools working in this repo

## No agent identity, anywhere

Do not add your name, brand, tool identity, model name, "Co-Authored-By"
trailer, badge, watermark, footer, or any other self-attribution anywhere
in this repository. This applies everywhere, including but not limited to:

- Git commit `author` / `committer` fields — commits must be attributed to
  the human user's own configured git identity, never to a CLI/tool/model.
- Commit message bodies and trailers (no "Co-Authored-By: <tool/model>",
  no "Generated by X", no "🤖 Generated with ...").
- README.md and any other documentation file.
- Code comments and file headers.
- Pull request titles/descriptions.
- Any generated file (logs, reports, docs) committed to the repo.

If your tooling defaults to injecting a `Co-Authored-By` trailer or setting
its own git author identity, disable that behavior before committing. If it
cannot be disabled, ask the user before committing rather than pushing
attribution into the repo.

This rule was added after a prior commit (`Puku CLI` / `Opus 4.8`,
`noreply@puku.sh`) landed on GitHub with tool identity in the author and
trailer fields. Don't repeat that.
