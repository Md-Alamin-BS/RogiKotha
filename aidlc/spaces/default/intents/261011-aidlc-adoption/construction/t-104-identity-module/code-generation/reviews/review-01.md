### Summary

The identity boundary holds in the code as built. Projections carry no id and no username for anonymous personas; logs and audit rows never pair an account with a persona; `persona_links` is touched only from the allowlist; migration 0010's two partial indexes and the deferrable `ON DELETE SET NULL` key are pinned by tests; `CommandPorts` is not extended; the adversarial tests are present and green. The main concern is containment rather than a current leak: the container hands `ownership` to all web server code, and the BR3.6 scans cover only actions and API routes, so narrow the container before U47 builds the author and `/me` pages.
