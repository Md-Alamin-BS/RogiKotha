### Summary

The correction path is sound. Only the author may correct or open the edit form, and everyone else gets the same not_found. The command uses the publish gate, takes a row lock with an expectedVersion check, and writes one version row, one audit row and one outbox event in a single transaction, with the persona as actor. The rate-limit slot is released on any refusal or rollback. Non-authors never receive the version list, and no account or persona id reaches them. Two Major gaps are worth weighing before approval, both in what Show original shows readers. Seeded reviews, which are the whole demo, get a wrong or partial original. A field that was empty before the correction disappears from the original instead of reading "Not provided".
