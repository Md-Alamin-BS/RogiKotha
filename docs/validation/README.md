# docs/validation

One record per validated task of the demo build, written by the independent validator session
(see `docs/implementation/README.md` §4 for the prompt and the required structure). File name:
`T-xxx.md`; phase-level records: `PHASE-n.md`. The concise verdict index stays in
`docs/status/validation-log.md`.

A record here is validation evidence. It may name the validator model id on its first line; that is
the only place in the repository where a model name appears, and it is never an attribution.
