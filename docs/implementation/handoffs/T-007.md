## Fragile or surprising

- **`seed.int.test.ts` cannot run inside `pnpm test`/`pnpm check`/`pnpm test:int`.** It resets
  `DATABASE_URL_TEST` itself and would race `packages/database`'s own int-test project, which resets
  the *same* physical database in its own `beforeAll` — two concurrent `DROP SCHEMA public CASCADE`
  calls is real corruption risk, not a hypothetical. `vitest.config.ts` excludes it by default and only
  lifts the exclusion when `process.argv` names the file directly (Vitest's exclude is not bypassed by
  passing an explicit file path — confirmed empirically, "No test files found" the first time I tried
  it). Run it with: `pnpm --filter @rogikotha/test-support exec vitest run src/seed/seed.int.test.ts`.
  `ISS-167`.
- **This package's automatic `@types/node` inclusion silently does not fire** under plain
  `tsc -p tsconfig.json`, even though `packages/database` (byte-identical `tsconfig.json`) is fine —
  confirmed with `tsc --listFiles` (zero vs. dozens of `@types/node` files loaded), root cause not
  found. Fixed with `--types node` on the package's own `typecheck` script plus five
  `/// <reference types="node" />` directives (for ESLint's separate type-aware pass, which reads
  `tsconfig.json` directly and ignores that CLI flag). `ISS-166`.
- **`STORAGE_ROOT=./.data/storage` has no documented anchor** and resolved relative to
  `process.cwd()` (which is `packages/test-support` under `pnpm --filter`) instead of the repo root —
  found live (derivatives landed in the wrong directory), fixed in `seed-evidence.ts`. `ISS-169`.
- **`persona_links.review_id` has a real FK to `reviews.id`, not a free-text seed ref** — an anonymous
  persona for a *review* must be created with `reviewId: null` first and back-filled after the review
  row exists (chicken-and-egg: the review needs `authorPersonaId` too). Anonymous personas moved out of
  `seed-accounts.ts` entirely into `seed-content.ts`'s `ensureAnonymousPersona()` because of this — see
  that function's own comment before changing the seed step order.
- **`@node-rs/argon2`'s `Algorithm` is an ambient `const enum`**, which `verbatimModuleSyntax` refuses
  to import as a value (TS2748) — both places that hash a password pass the raw numeric value (`2` =
  `Algorithm.Argon2id`) with a comment, not the enum member.
