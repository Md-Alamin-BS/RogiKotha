## Fragile or surprising

- The plan's filtered command `pnpm test:int -- validator-probes …` passes the `--` on to
  Vitest, which then drops the filters and runs every database file. Use the form without `--`.
- `information_schema.columns` hides columns from a role that holds nothing on them, so P3 reads
  the `auth_users` column list as the owner and then checks each column as the worker.
- The test files were not Prettier-clean before this Unit either (`HEAD` versions fail
  `prettier --check`). They were not reformatted; `format:check` arrives with T-010.
