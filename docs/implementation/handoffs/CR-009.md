## What exists now

more. 136 specifiers across 47 files were changed, by stripping the suffix only. Directory
imports keep `/index` (`./schema/index`, `./search/index`, `./queue/index`), the same form
CR-005 used in `packages/contracts`. `@rogikotha/database` is now in `transpilePackages` in
`apps/web/next.config.ts`. A server component or route handler in `apps/web` can now import

with a throwaway page, which was then removed. `ISS-183` is closed in `ISSUES.md`. The
package's logic, types, exports, schema and migrations are unchanged.
