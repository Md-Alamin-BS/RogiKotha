## Fragile or surprising

- **`packages/contracts` cannot be imported from `apps/web` at all right now** — every relative
  import inside it uses a `.js` suffix (`from './enums.js'`), which Next's Turbopack build cannot
  resolve through `transpilePackages`, no matter which file or subpath is imported. This task is the
  first to try, so it was never caught before; the emergency numbers are hand-typed locally with a
  Vitest-only parity test as a workaround. Full write-up, repro and what was tried: `ISS-125`. **This
  blocks any future page that needs a real `packages/contracts` view model** — read `ISS-125` before
  assuming a `DEFAULT_...`/view-model import from `@rogikotha/contracts` will just work in `apps/web`.
- **`@rogikotha/i18n`'s main barrel (`.`) is not safe to import from a component that only needs
  formatting** — it also re-exports `routing.ts`, whose `createNavigation()` call fails to resolve
  `next/navigation` outside a real Next.js build (same root cause as `ISS-053`, T-006). Added a
  `./format` subpath export (`packages/i18n/package.json`) so `formatDate`/`formatDigits`/etc. can be
  imported without dragging routing in; `Emergency.tsx` uses it, `Emergency.test.tsx` proves it works
  under Vitest without mocking `@/i18n/routing`.
- **`ViewShell`'s `<h1>` is now conditional on `title`** — a page whose own content brings a complete
  heading (Emergency's `.emerg-head h1`, About/Policy's `.about-head h1`, none of them `.display`)
  passes `title=""` to `ViewShell` on purpose. If you add a new page that also wants its content to
  own the heading, do the same; if you want `ViewShell`'s generic placeholder heading, pass a real
  title (every existing placeholder page still does this unchanged).
- **A fresh worktree has no `.env`** — `git worktree` only replicates tracked files, and `.env` is
  git-ignored; without it `packages/database`'s integration tests fail with `SASL:
  SCRAM-SERVER-FIRST-MESSAGE: client password must be a string`. Copied the root `.env` from the main
  checkout (`D:/git_repos/RogiKotha/.env`, local Docker Postgres creds, not a real secret) — see
  `ISS-130` for whether `.worktreeinclude` should be automating this.
