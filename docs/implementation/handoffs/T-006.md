  — `ISS-045`.

  `ISS-049`. A stray `pnpm-workspace.yaml` `allowBuilds` stub with placeholder text got auto-written
  by one `pnpm install`; reverted, not committed.

  `scripts/` directory (only root `tools/**` is fully ignored) — worked around with a file-scoped
  `eslint-disable` comment in each of the three new scripts — `ISS-046`.
