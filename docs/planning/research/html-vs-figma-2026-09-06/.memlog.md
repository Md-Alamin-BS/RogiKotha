- (decision) Single-question decision: push HTML further, or move to Figma (or Figma-adjacent) for the full demo before fixing P3 defects.
- (source) Wikipedia article on Figma (https://en.wikipedia.org/wiki/Figma) confirms that Figma Make, Figma Sites, Figma Buzz, and Figma Draw were all announced at Config 2025 on May 7, 2025; Figma Make is powered by Anthropic's Claude 3.7.
- (source) Framer pricing page (https://www.framer.com/pricing) confirms 2026 tiers: Free $0 / Basic $10/mo / Pro $30/mo / Enterprise custom. Additional editors $20/mo.
- (source) Penpot GitHub (https://github.com/penpot/penpot): ~59,700 stars, ~4,100 forks, MPL-2.0 license, sustained 2025–2026 activity, version 2.8.1 dated 2025-08-01 per Wikipedia, latest milestone labels visible "2.18.0 / 2.19.0". Webflow acquired Vidoso.ai in March 2026 (per Wikipedia).
- (source) Vercel blog "AI-powered prototyping with design systems" (https://vercel.com/blog/ai-powered-prototyping-with-design-systems) — explicit thesis: "Design systems are context that makes AI prototyping effective. Models need to understand how components are structured, how they are styled, and how they relate to each other in context." Quote: "Most AI tools have cracked the 'fast' and 'collaborative' parts, but can struggle with feeling 'on-brand'." Code and Theory cited: "Time-to-prototype dropped by 75%."
- (source) Vercel blog "Teaching agents product design at Vercel" (https://vercel.com/blog/teaching-agents-product-design-at-vercel) — "What they cannot do is understand why those patterns exist. Code shows agents what shipped, not why one component, phrase, or interaction became your standard."
- (source) Framer vs Figma comparison (https://www.framer.com/compare/framer-vs-figma) — Framer positions itself for "design, publish, manage, and improve a professional website from one visual workspace"; Figma is positioned as "product design and prototyping" — different layers of the stack.
- (source) Penpot positioned as "open-source, web-based and self-hostable design platform" with native design tokens, components, variants, MCP server, and full SVG support (https://penpot.app/).
- (source) Rauno Freiberg personal site (https://raunofreiberg.com/): "Make it fast. Make it beautiful. Make it consistent. Make it carefully. Make it timeless. Make it soulful. Make it." — Estonian interaction designer working with Vercel and Devouring Details.
- (claim) Consensus in 2026 from major engineering-led design orgs (Vercel, Linear alumni, Stripe, Notion) is that the medium of design is code-shaped; Figma's own Config 2025 keynote framed the response as "design-to-code generation" (Make, Sites) — meaning even Figma is now pulling toward the prototype-as-code side rather than defending Figma-native UI as the deliverable.
- (claim) Figma Make produces a generated code artifact, not a Figma-only deliverable. That is the strongest industry signal that the gap between "Figma design" and "running HTML prototype" has narrowed enough that re-platforming onto Figma first costs you more than it buys.
- (claim) Solo-founder time math: switching 8 working HTML views into a Figma file is multi-week; the Impeccable audit already verified the existing prototype meets WCAG AA contrast in both themes and Bengali localization works — those are problems Figma cannot solve cheaper than the existing repo.
- (claim) For Bengali/Indic typography specifically, Figma renders the same OTF/TTF as a browser does — there is no intrinsic Bengali advantage in Figma; in fact, Figma lacks the runtime logic (bn() digit substitution, lang attr, prefers-color-scheme handling) that already works in the HTML prototype.
- (event) Three counter-arguments recorded: Figma Make / Sites are now real products (May 2025 launch) and the AI gap to "polished output" is closing; for brand and pitch contexts Figma remains the standard; teams that don't ship code still default to Figma.
- (event) Two open questions for the founder before commit: (a) what does "public demo" mean — investor/user/partner? (b) is there a half-step (e.g., design the missing flows in Figma Make while keeping the existing repo) that's better than a binary fork?
