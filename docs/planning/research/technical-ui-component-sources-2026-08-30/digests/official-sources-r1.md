# Official-source digest — UI component candidates

Accessed: 2026-08-30

- **shadcn/ui:** Official docs describe open-code, accessible, customizable components and free open-source React blocks, including dashboard/sidebar/login examples. Best fit as the source-owned component layer. Sources: https://ui.shadcn.com/docs and https://ui.shadcn.com/blocks. Confidence: high.
- **Radix Primitives:** Official docs/repository describe unstyled accessible primitives with WAI-ARIA patterns, focus management and keyboard behavior; MIT licence. Best fit beneath complex interactive controls. Sources: https://www.radix-ui.com/primitives/docs/overview/introduction and https://github.com/radix-ui/primitives. Confidence: high.
- **Tailwind CSS:** Official docs support class-driven light/dark variants and custom selectors. Existing project selection remains the styling/token foundation. Source: https://tailwindcss.com/docs/dark-mode. Confidence: high.
- **HyperUI:** Official repository provides copy/paste Tailwind CSS v4 components under MIT with no package required. Good layout/pattern inspiration, but copied markup still needs semantic/accessibility review and registry entry. Source: https://github.com/markmead/hyperui. Confidence: high.
- **Flowbite:** Official docs say open-source Tailwind components support dark mode and React/Next.js; released code is MIT while documentation and Pro have separate terms. Use only clearly free core code and record provenance. Sources: https://flowbite.com/docs/getting-started/introduction/ and https://flowbite.com/docs/getting-started/license/. Confidence: high.
- **daisyUI:** Official docs/repository describe a Tailwind semantic CSS layer, built-in light/dark/custom themes and MIT commercial use. It is useful for theme exploration but would duplicate the selected shadcn/Radix component layer if installed wholesale. Sources: https://github.com/saadeghi/daisyui and https://github.com/saadeghi/daisyui/blob/master/packages/docs/src/routes/%28routes%29/docs/themes/%2Bpage.md?plain=1. Confidence: high.
- **Magic UI:** Official docs/repository provide MIT copy/paste animated React/Tailwind components, while many templates/components are separately paid Pro. Use at most restrained free effects after reduced-motion, bundle and healthcare-trust review. Sources: https://magicui.design/docs and https://github.com/magicuidesign/magicui. Confidence: high.
- **Motion Primitives:** Official repository is MIT but explicitly beta. Optional for one or two low-risk interactions only; copied behavior needs accessibility and maintenance review. Source: https://github.com/ibelick/motion-primitives. Confidence: high.
- **Tremor:** Official repository offers Apache-2.0 copy/paste React/Tailwind/Radix components focused on modern dashboards. Strong admin visualization/pattern source; do not copy an entire generic dashboard. Source: https://github.com/tremorlabs/tremor. Confidence: high.
- **TanStack Table:** Official docs/repository describe a headless, fully customizable React-compatible table engine under MIT. Strong candidate if dummy admin tables need realistic sorting/filtering; native tables remain simpler for small datasets. Sources: https://tanstack.com/table/latest/docs/overview and https://github.com/TanStack/table. Confidence: high.
- **Recharts:** Official repository describes a composable React/SVG chart library under MIT. Use only when a chart materially improves admin understanding; all values require text/table equivalents. Source: https://github.com/recharts/recharts. Confidence: high.
- **React Bits:** Official repository currently states MIT plus Commons Clause rather than plain MIT and is animation-heavy. Exclude from the default shortlist unless exact component terms and healthcare suitability are separately approved. Source: https://github.com/DavidHDev/react-bits. Confidence: high.

Selection conclusion: build five concepts from one owned component foundation. External galleries are inputs, not design systems to mix indiscriminately.
