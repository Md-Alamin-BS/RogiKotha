# Research brief — free UI component sources

Decision: Which current free/open-source component sources should the Gate 4 dummy UI agent consider for five cohesive RogiKotha concepts and an admin panel?

Method: Quick, straightforward technical selection; official documentation/repositories only; verify licence, free/paid boundary, framework fit, accessibility posture and likely use. Project requirements shape the screen, but are not evidence about third-party projects.

Hard gates: commercial use permitted; source or package can be self-hosted; compatible with React/Next.js/Tailwind or usable as framework-agnostic inspiration; no required paid subscription; no floating CDN dependency; accessibility must be reviewable.

Output: a compact cited shortlist embedded in the implementation handoff prompt. The implementation agent must recheck versions/licences before copying or installing anything and register every adapted component.
