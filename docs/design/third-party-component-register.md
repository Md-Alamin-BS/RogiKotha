**FD-027 / Concept 04b (2026-09-06):** Concept 04b ships no third-party UI components. Fonts are system + Noto Sans Bengali (no webfont load). Motion is CSS-only (5 primitives); no GSAP, no Web Animations API. The chosen direction does not depend on any registered component — the no-third-party stance is a deliberate attribute of the 04b minimal-pass direction, not an oversight.

Registry packages installed normally are tracked in the dependency selection and lockfile. This register covers copied/adapted gallery, registry, illustration, animation and component source.
