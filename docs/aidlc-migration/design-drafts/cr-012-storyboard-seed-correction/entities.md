# Entities — U6 `cr-012-storyboard-seed-correction`

Source of truth for the data shape this Unit works on. The Unit adds no table, no column and no migration. Its entities are the demo-data pipeline (prototype dataset → generated corpus → seeded database rows), the derivation and padding rules that pipeline applies, and the documents and records it corrects. Built from CR-012 with its FD-089 amendment, FD-039, FD-086, FD-089, `packages/test-support/scripts/port-corpus.mjs`, `packages/test-support/src/{corpus,seed}/`, the schemas in `packages/database/src/schema/`, `05-demo-storyboard.md` and the T-106, T-401 and T-409 task files. Workflows and state transitions are in `functional-spec.md`; decision logic is in `rules.md`.

The collection ids `DC1`–`DC22` (§ 6 of `functional-spec.md`) and the correction ids `SC1`–`SC12` (§ 8) are stable within this Unit's record.

## Summary

- **PrototypeDataset → CorpusCollection → SeededRow** is the pipeline. The prototype is read-only and decides the data (FD-039). The port turns each **PrototypeCollection** into a generated **CorpusCollection**; the seed's **SeedSteps** turn corpus records into database rows, each idempotent by a natural key.
- **PortRule** is where this Unit changes behaviour: five rules change (alias language, follow-up reading, thread persona reuse, hue pinning, a bookmark export) and each leaves every pre-FD-089 record exactly as it was.
- **WithheldRecord** is the one prototype record the seed does not load: n8, a reporter notice that FD-086 rules out.
- **SyntheticAccount** and **Persona** carry identity. An anonymous persona lives in one thread; the **AliasIsolationProof** names r2 and `anon_author_r2` (Question 1).
- **ModerationCaseSeed** with **ReasonPadding** fixes ISS-221: only MOD-2033 is padded, with `factual`.
- **CollectionExpectation** is the per-collection count the tests compare with the prototype. **DocumentCorrection**, **BilingualReviewItem** and **IssueRow** are the document and record changes.
